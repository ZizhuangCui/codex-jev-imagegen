# Roadmap

## v0.1.0 — Experimental skill

- [x] Jev plan and text-report review helper.
- [x] Explicit uncertainty, credential and transport fallbacks.
- [x] Codex built-in image generation workflow instructions.
- [x] Offline checks, portable installation, English and Chinese documentation.
- [x] GPT Image family and Seedream 5.0 Pro capability notes.

## v0.2.0 — Multi-model connected-tool routing

- [x] GPT Image, Nano Banana and Seedream version catalog.
- [x] Explicit model resolution and operation/reference-capacity checks.
- [x] Agent handoff to observed tools, with no silent model substitution.
- [x] Offline routing checks and bilingual model-support summary.

## Next — Validate usefulness

- [ ] Live Jev transport verification with a maintainer-provided key.
- [ ] Complete and record a real image generation/edit cycle.
- [ ] Build a permission-cleared bilingual evaluation set.
- [ ] Compare Codex-only and Jev-assisted decisions on the same image backend.
- [ ] Calibrate thresholds by question type and report coverage as well as accuracy.

## Later — External image providers

- [ ] Implement Seedream 5.0 Pro for a verified provider contract and credential flow.
- [ ] Add explicit GPT Image API adapters only if needed beyond the built-in tool.

No dates or performance improvements are promised. Connected-tool routing is implemented; standalone API clients and live provider validation remain future work.
